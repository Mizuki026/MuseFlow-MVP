# 验证 MuseFlow MVP 界面与操作流程

Status: needs-info

## 目标

用模拟数据验证创建任务、状态查询、结果预览、失败恢复与历史记录的操作体验。

## 范围与约束

纯前端、内存数据、一个模拟 Provider；不实现真实后端、计费、鉴权或模型调用。
参考产品规格：`docs/product/museflow-mvp-product-design.md`。

## 原型与进度

- 分支：`prototype/museflow-ui`
- 入口：`demo/index.html`；启动：`node demo/server.mjs`
- 变体 A：双栏创作工作台；B：引导式创建；C：任务控制台。
- 模拟成功、两次超时恢复、永久失败和手动重试关联。
- 下一步：用户体验原型，选择布局并指出流程问题。

## 验收与结论

已通过本机 Edge / Playwright 验收：创建→排队→生成→完成及下载、两次超时恢复、永久失败后修改描述、临时失败后新建关联重试任务、参数复用、参考图预览、历史筛选分页和布局切换。
三种布局在 390px 手机宽度下均无页面横向溢出，浏览器无 JavaScript 异常。
JavaScript 语法检查通过；默认布局已进行截图视觉检查。
复验入口：`demo/check-demo.cjs`。真实后端可靠性不属于本次验证范围。
布局结论待用户反馈；不将设计假设视为已验证。

## Comments

原型仅用于界面评审，不代表后端可靠性或真实模型能力。
